# Design Intake Placeholder

Use this folder when a round depends on screenshot or mockup absorption.

Recommended contents:
- 1 to 3 representative screenshots
- a short note describing which page is in scope
- a short note describing what is already confirmed versus still inferred

Keep this folder lightweight.

Do not use it as:
- a dumping ground for every image ever seen
- a replacement for project-local working memory
- a place to store private production assets in the public sample package
